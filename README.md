wireless_data_acquisition
Projet créé dans le cadre d'un PFE, en partenariat entre le 3DI et et le 3DK, visant à créer une plateforme d'acquisition de données sans fils.
Tâche de la carte D'acquisition POC : 
_ Prendre des mesures chaque 10 ms 
_ Entrée 4 Capteurs 
_ Sauvegarde Sur Carte SD 4Go : Retirable Manuelement ou possibilité de télécharger le fichier CSV via L'interface Web avec Wifi 
_ Visualisation des données en temps réel via IHM 
_ Configuration de lancement de la mesure et aussi choix des capteurs possible manuelement directement sur le POC 
_ UN écran LCD 
_ un appreil embarqué autonome avec un système de recharge de batterie intégrer 
_ commander la carte à distant via l'interface web
